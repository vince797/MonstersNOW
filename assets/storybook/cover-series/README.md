# MonstersNOW cover series

These square background plates share one catalog-cover system: a clean title band, an open center for the customer's monster, story-specific scenery, and a consistent series credit. The monster, title, and credit remain separate HTML/CSS layers so the child's personalized character can be swapped without recreating the background.

The public catalog intentionally uses a different sample monster on each title to demonstrate personalization range. A real customer's chosen monster remains consistent across every book made for that child.

The 1254 × 1254 JPEG files are web catalog concepts. Final Lulu cover files should be regenerated or upscaled against the exact trim, bleed, spine, barcode, and resolution requirements in the selected Lulu template.
