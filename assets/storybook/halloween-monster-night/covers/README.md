# Halloween Monster Night cover concepts

These square images are reusable front-cover background plates for the 8.5 x 8.5 inch book:

- `background-minimal-halloween-v3.png` — selected series direction; simple thematic background keeps the personalized monster and title dominant.
- `background-porch-gate-v1.png` — selected catalog direction; clearest foreground for a replaceable monster at thumbnail size.
- `background-town-square-v1.png` — broader parade-world alternative.
- `background-garden-arch-v1.png` — more magical, ornate alternative.
- `demo-monster-cutout-v1.png` — catalog-only demonstration character. Customer books must replace it with the selected generated monster.

The generated backgrounds intentionally contain no title or character. Add title, starring line, and monster as separate production layers so they remain editable and personalized.

The source plates are 1254 x 1254 pixels, suitable for web concepts but only about 143 PPI across an 8.75 inch full-bleed front panel. They are **not final 300 PPI print masters**. A final front panel should be at least 2625 x 2625 pixels for 8.5 inch trim plus 0.125 inch bleed on all sides. Build the complete Lulu cover only after requesting the exact template/dimensions for the selected binding, paper, and 32-page count; the output must be a one-page back-spine-front PDF.

Keep title, names, the star, faces, and the personalized monster inside the applicable safety margin. Hardcover casewrap needs substantially more protected space than paperback because of wrap and hinge areas.

## Series system

Every MonstersNOW cover should keep the same five layers: small `A MonstersNOW Original` imprint, two-line high-contrast title, simple theme-specific full-bleed background, large centered personalized monster, and a short `Starring ...` line. Keep the monster at roughly 60–65% of the front-panel height. Change only the restrained border symbols and accent palette per story, while preserving the hierarchy and placement so the monster remains the hero and the books read as one series.
