# warm-curly-dark: four-pose art candidate

Generated with OpenAI image generation from the actual Halloween storybook masters. This set remains a visual direction sample awaiting human approval. It must not be called print-ready or replace approval flags.

- `porch.png`: welcoming three-quarter-right standing pose, pumpkin bucket held in both hands.
- `garden-quiet.png`: quieter hesitant expression for the garden challenge; separate provenance JSON records exact source bytes.
- `garden.png`: hopeful rightward walking pose, pumpkin bucket carried by one handle.
- `seated-home.png`: seated, knees bent, hands under cheeks; no baked-in sofa, table or bucket.
- `manifest.json`: exact native dimensions, identities, hashes, alpha inspection and baseline hints.

All four are original 1024 x 1536 RGBA files with no post-generation image edits. Original backgrounds remain unchanged; the catalog exposes this set only as an unapproved candidate. Source core alpha is 251–254 rather than 255, inherited from image generation. RGB outside the alpha silhouette contains a glow, but checkerboard and plate renders confirm that the alpha excludes it; do not remove the alpha channel.

The contact sheet at `output/character-art-review/warm-curly-dark-three-pose-alpha-review.png` is a compositing QA render, not new generative scene art. It retains the source pixels over existing unchanged backgrounds. It intentionally does not claim final per-scene sizing, relighting, contact shadows or foreground masking. The seated pose particularly needs sofa alignment and table ordering when integrated.
